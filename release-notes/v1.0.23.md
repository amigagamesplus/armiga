### Added

- The system update screen now shows the publication date and size of the new version, and the download and verification screens show progress in MB, speed and remaining time.

### Fixed

- The update download bar no longer sticks at 99% while the file is still downloading: it now uses the real size of the update.
- Slow connections no longer abort the update download after 5 minutes.
- The update verification no longer freezes the screen while it runs, and its result is saved to a log file.

### Changed

- Linux kernel updated to 7.3.1.
- The update progress bar is wider and shows the percentage inside it.
- Graphics drivers (Mesa) updated to 26.3.0-rc3.
- The rows in System Diagnostics now have more vertical spacing.
