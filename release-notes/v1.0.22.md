### Added
- Game card in the catalog now shows year, developer, publisher and genre as tags (metadata bundled in the image; falls back to the title when the CRC is unknown).

- System Diagnostics can now save a text report (system information, logs and settings, without network details) to the diagnostics folder by pressing [B].

### Fixed

- The Samba and Bluetooth settings are now respected at boot: with them disabled, Samba and Bluetooth no longer start (they used to start anyway).

### Changed

- RetroArch updated to nightly 2242d04.
- SDL3_image updated to 3.4.8.
- Graphics drivers (Mesa) updated to 26.3.0-rc2.
- Volume changes made with the hardware buttons are now saved after a short delay instead of on every button press.
