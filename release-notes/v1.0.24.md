### Added

- The console now vibrates briefly when you go back to the previous screen. MODE+A turns this vibration and the click sound on or off.
- New color theme: Teal / Ivory, with a teal background, ivory text and an orange accent.
- New Screenshots screen in the main menu to browse, view full screen and delete the screenshots taken in RetroArch.
- The console also vibrates when you confirm power off or restart.

### Fixed

- The boot splash no longer shows up again on the screen when the console powers off or restarts.
- The text cursor no longer blinks on the screen when the console powers off or restarts.
- RetroArch settings are now saved safely, so an unclean shutdown can no longer leave the configuration empty or reset to defaults.

### Changed

- The System Update screen now shows the installed version in a tile, and the new version is shown with a leading v.
- The last played game tags (folder and play time) now sit on the right, so they get in the way less.
- New ARMIGA logo on the main screen, tinted with the text color of the selected theme.
- New boot splash image.
- Buildroot updated to 2026.08.1.
- Screen Brightness is now Screen Calibration: next to brightness it adds a gamma adjustment (RG40XX H only) and a test chart.
- The disabled icons in the status bar (Wi-Fi, Bluetooth, SSH and updates) now use a dimmed version of the theme text color instead of a fixed greenish gray.
- The status bar has a new look: the icons and the clock and battery now sit in a capsule inside a larger capsule.
- Linux kernel updated to 7.4-rc2.
- Graphics drivers (Mesa) updated to 26.3.0.
