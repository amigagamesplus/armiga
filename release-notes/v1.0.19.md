### Added

- New **Pastel Navy** theme: dark navy background, soft pastel text and orange accents.
- Custom cover art: put a PNG named exactly like the game's `.lha` file (without the extension) in `amiga_data/covers/custom/` and it will be shown in the Amiga Catalog instead of the downloaded cover. Useful for games the catalog does not recognize or has no cover for.

### Changed

- Main menu redesigned: the description of the selected option now sits in its own tile that adapts to the text length, and the system info (CPU temperature, CPU load, RAM and free space) is shown as four tiles with large, readable numbers.
- Amiga Catalog: the cover now fills the full height of its card, and the info cards use the theme colors consistently.
- The footer text (button hints and version) is now vertically centered below the separator line.
- Kickstart checker (ARexx Scripts): clearer output, with one short line per Kickstart marked `[OK]`, `[INCORRECTO]` or `[NO EXISTE]` and a final summary. Hashes are only shown when a file does not match.
